AI 서술형 평가 도우미 — 채점·피드백 체계 정리

test4school.vercel.app · 2026년 8월 28일 기준 · 본문의 "실측"은 모두 실제 배포 서버에서 채점해 확인한 결과입니다

1. 채점이 이루어지는 순서

  1. 학생이 평가 코드와 답안을 제출한다. 학생 브라우저에는 문항·이미지만 내려가고 모범답안·채점지침·교사 시트 주소는 서버만 안다.
  2. 서버가 Supabase에서 문항·모범답안·평가 주의 사항·단원 정보를 직접 조회한다.
  3. 문항 1~3번을 동시에 채점한다 (GPT-4o + 지도서 벡터스토어 file search). 문항별 독립 호출이라 한 문항이 실패해도 나머지는 계속된다.
  4. 생성된 피드백이 검증 단계를 통과한다: 쪽수 범위 검사 → 모범답안 유출 검사(필요 시 교정) → 점수 추출.
  5. 학생 화면에 피드백이 표시되고, 5단계에서 교사 개인 결과 시트에 저장된다.

2. 만점의 기준 — 무엇과 비교해 채점하는가

2-1. 교사가 모범답안을 등록한 경우

교사의 모범답안이 곧 만점의 정의다. 모범답안과 같은 내용을 같은 형태로 답하면 4점이며, AI가 모범답안에 없는 요소(추가 설명·이유·예시)를 스스로 요구 조건으로 만들어 감점하는 것은 금지된다.

답안의 형태(낱말 / 낱말 나열 / 짧은 구 / 문장 서술)는 AI가 아니라 서버 코드가 모범답안을 보고 판정해 프롬프트에 넣는다. AI에게 맡기면 채점할 때마다 판단이 달라져 같은 답을 쓴 두 학생이 다른 점수를 받을 수 있기 때문이다.

실측 사례 — 모범답안이 "경복궁"(낱말)인 문항에서, 예전 척도는 "완성된 문장이 아니다"라며 정답에 2점을 줬다. 형태 판정 도입 후 같은 답이 4점. 반대로 낱말·나열 문항이 아닌 곳의 척도는 그대로라, 서술형 대조군 점수는 변하지 않았다.

2-2. 모범답안이 없는 경우

AI가 채점 전에 file search로 교과서(지도서) 내용을 찾아 스스로 모범답안을 세우고, 그것을 기준으로 같은 방식으로 채점한다. 스스로 세운 모범답안도 교사 등록본과 동일하게 취급한다(낮은 점수에는 노출 금지). 이 동작은 예전 어시스턴트 시절의 원래 설계로, 마이그레이션 때 유실됐다가 복원됐다.

실측 사례 — 모범답안 없는 역사 문항(김상헌 vs 최명길)에서 좋은답 4점 / 부분 3점 / 오답 2점의 정확한 계단이 나왔고, "김상헌은 전쟁을 피하고 싶어했다"는 사실 오류를 벡터스토어 근거만으로 잡아 감점했다. 같은 답안을 4번 반복 채점해 4번 모두 같은 점수(일관성 확인).

생각·느낌·상상을 요구하는 문항(정답이 하나로 정해지지 않는 문항)은 ① 문항 요구와의 관련성 ② 자료 내용과의 관련성 ③ 구체성으로 판단한다. 상상이라는 이유로 무조건 높은 점수를 주지 않는다.

3. 채점 척도

기본 척도 (1~4점)기준
4점 매우 우수요구 내용을 모두 포함하고 문항이 요구하는 형태를 갖춤. 요소가 하나라도 빠지면 나머지가 아무리 좋아도 4점 불가 (3점 이하).
3점 우수요구 내용 중 일부가 빠졌으나 형태는 갖춤.
2점 보통요구 내용의 일부만 담김. 서술 요구 문항에 핵심 단어만 나열. (낱말·나열이 정답인 문항에는 이 사유를 적용하지 않음)
1점 노력 요함요구 내용이 대부분 빠짐.

교사가 평가 주의 사항에서 다른 척도를 지정하면 반드시 그 척도로 채점한다 (상/중/하, 5점, 도달/미도달 등). 이때도 "채점 결과:" 줄의 형식은 유지돼 점수가 정상적으로 시트에 저장된다.

4. 피드백 — 항상 5개 문단

문단내용
1문단문항을 그대로 보여줌
2문단학생이 쓴 답안을 그대로 보여줌
3문단"채점 결과: (척도값)(등급) - (이유)" — 이 줄에서 점수를 추출해 시트에 저장
4문단점수 수준에 따라 달라짐 (아래 표)
5문단칭찬과 격려, 선생님께 질문하도록 안내 (문항마다 다른 문장)

4문단의 수준별 규칙 — "AI가 학생의 사고를 대신하지 않는다"

수준제공하는 것금지되는 것
1~2점
(낮음)		관련 개념어·소재의 이름만 제시 (예: "'부피', '상태 변화'라는 말을 찾아보세요") + 공부할 교과서 쪽수모범답안 문장 전체, 정답이 되는 결론 진술 자체 ("부피는 늘어난다" 등)
3점
(중간)		빠진 내용을 스스로 생각하게 하는 유도 질문 (자기 말로 새로 쓴 질문)모범답안의 문장·표현을 그대로 인용하기
4점
(최고)		모범답안 전체 공개 + 자기 답안과 비교·점검 권유—

교사 지정 척도에도 같은 원칙이 적용된다 — 예: 도달/미도달 척도의 '미도달'은 낮은 수준 규칙을 따른다.

실측 사례 (1점 학생 "몰라요 어려워요")
고치기 전: "물이 얼면 부피는 늘어나고 무게는 변하지 않는다는 것을 이해하는 것이 중요합니다…" ← 정답을 통째로 알려줌
고친 후: "'부피', '무게', '상태 변화'라는 단어를 교과서에서 찾아보세요. 교과서 44쪽을 공부해 보세요." ← 개념어와 쪽수만

유출 방지 이중 장치

지침만으로는 AI가 가끔 결론을 흘리기 때문에, 서버 코드가 출력을 한 번 더 검사한다: 낮은 점수인데 모범답안의 연속 조각(문항에는 없는 12자 이상)이 피드백에 있으면, 그 부분만 개념어 힌트로 바꾸는 교정 호출이 자동으로 돈다. 유출이 감지된 경우에만 돌므로 평소 비용·지연은 없다. AI가 어미만 바꿔 옮기는 수법("않습니다"→"않는다는")까지 잡도록 실측으로 조정했다.

5. 교사의 '평가 주의 사항' = 최상위 설정

문항 설계 5단계에서 입력하는 평가 주의 사항은 기본 규칙보다 우선한다. 네 방향 모두 실제 배포 서버에서 실측으로 확인했다.

교사가 지정하면실측확인된 동작
채점 척도 ("도달/미도달 2단계로만")✓"채점 결과: 미도달"로 채점·저장됨
어투 ("전부 반말로, 친구처럼")✓"…생각해볼래? 선생님께 꼭 물어봐!" — 전체 반말
언어 ("피드백은 영어로")✓4~5문단 영어 작성, 점수 줄은 한국어 형식 유지 → 점수 추출 정상
피드백 방식 ("모든 점수에서 모범답안을 보여주세요")✓1점 학생에게도 모범답안 공개. 유출 방지 장치도 이 지정을 인식해 개입하지 않음

6. 교과서 쪽수 안내

문제였던 것: AI가 쪽수를 지어냈다 (지도서 자체 쪽번호를 교과서 쪽으로 인용). 학생이 실제로 교과서를 펼치므로 틀린 쪽수는 안내하지 않는 것만 못하다.

  • 지도서 원문에서 실제 교과서 쪽수 앵커를 추출해 (쪽수가 안 적힌 페이지는 앞뒤 페이지로 추정) 단원별 쪽 범위 표 422단원을 구축. 검증 결과 중앙오차 1쪽.
  • 채점 프롬프트에 그 범위를 알려주고, 출력에서 범위 밖 쪽수를 한 번 더 걸러낸다.
  • 표기는 "교과서 ○쪽"만 — 내부 파일명은 절대 노출하지 않는다.
  • 생각교실 문항은 쪽수가 나가지 않는다 (설계 의도: 대응하는 실물 교과서로 공부할 수 있는 문항이 아니므로). 대신 "이 단원의 ○○ 부분"처럼 내용으로 안내한다.
실측 — '물의 상태 변화' 단원(실제 범위 35~57쪽) 채점 3회에서 인용된 쪽수 56쪽 / 44~45쪽 / 44쪽, 전부 범위 안. 파일명 노출 없음.

8. 품질 측정 결과 (2026-08-26~28)

  • 천장 검사: 모범답안을 그대로 낸 학생이 만점을 받는가 — 생각교실 493자리 전수에서 455건(92.3%) 만점. (수정 전 표본은 6건 중 2건이었다. 만점이 안 나온 38건 중 6건은 이미 수리된 데이터로 재확인 시 만점 → 잔여 32건은 모범답안 쪽 결함)
  • 수준 변별: 완벽/부분/오답 3수준 답안 투입 — 완벽→만점 12/12, 오답→낮은 점수 정상. 부분 답안이 4점을 받는 관대함이 12자리 중 4건 (개선 여지).
  • 일관성: 같은 답안 4회 반복 채점 → 4회 모두 동일 점수.
  • 재현성: 같은 자리 2회 채점 56건 중 53건 동일 판정(94.6%) — 3점↔4점 경계는 흔들릴 수 있음.

9. 남아 있는 일

  • 생각교실 모범답안 32건 보강 — 문항이 묻는 것의 일부만 답하고 있는 자리. 채점은 문항 기준으로 정상 작동하므로 급하지 않으나, 교사가 가져올 때 보는 참고자료 품질 문제. 목록: scripts/model-answer-defects.json
  • 교사 제작 문항의 모범답안 채우기 — 6단계 'AI 확인'이 만든 모범답안이 저장되지 않고 버려진다. 채워넣기 버튼을 달면 새 문항부터는 자동으로 기준이 생긴다 (미착수).
  • 부분 답안 상단 관대함 — 요소 하나 빠진 답안에 4점이 나오는 경향 일부. "요소가 하나라도 빠지면 3점 이하" 지침을 배포했으나 재측정으로 효과 확정 필요.
  • 측정 도구: node scripts/check-grading-quality.mjs (실배포 서버로 3수준 채점, 학년·과목 층화 표본)
